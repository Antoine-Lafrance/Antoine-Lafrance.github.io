WEBSITE PLAN — Antoine Lafrance
================================

Goal: a professional personal site with two parts:
  1. About Me (home page): research first, then everything else.
  2. Blog: a place to write posts.

Hosting: GitHub Pages (this repo). Recommended stack: plain Jekyll, which
GitHub Pages builds natively. Posts are Markdown files, so there's no build
step to maintain. Use a small custom layout rather than a heavy academic
theme, so the design stays fully ours.


------------------------------------------------------------
1. SITE STRUCTURE
------------------------------------------------------------

  /            About Me (home)
  /blog/       Blog index (list of posts)
  /blog/<slug> Individual post
  /cv.pdf      Downloadable CV (English version, ideally)

Top nav (same on every page):  Antoine Lafrance   About · Research · Blog · CV
  - "Research" is an anchor link to the research section on the home page.
  - Footer: email · GitHub · LinkedIn · Google Scholar (if any) · © year

------------------------------------------------------------
3. BLOG DESIGN
------------------------------------------------------------

3.1  Blog index (/blog/)
     - Simple reverse-chronological list, grouped by year.
     - Each row: date · title · 1-line summary · tags.
     - Tag filter at top (e.g. research, ML, notes, personal).
     - No thumbnails by default: text-first and fast.

3.2  Post page
     - Narrow reading column (~680px max width), large readable body
       font, generous line height.
     - Header: title, date, reading time, tags.
     - Must support research-style writing:
         • LaTeX math (KaTeX)
         • Syntax-highlighted code blocks
         • Figures with captions
         • Footnotes / sidenotes
         • Optional table of contents for long posts
     - Footer: "← previous / next →" links, and an optional citation
       block (BibTeX) for technical posts.

3.3  Writing workflow
     - New post = new Markdown file in _posts/YYYY-MM-DD-title.md with a
       short front-matter header (title, date, tags, summary).
     - Push to main → GitHub Pages rebuilds automatically.
     - RSS/Atom feed (jekyll-feed) so people can subscribe.


------------------------------------------------------------
4. VISUAL DESIGN DIRECTION
------------------------------------------------------------

  - Tone: clean academic, quiet and confident; content over decoration.
  - Typography: serif for headings and blog body (e.g. Source Serif),
    clean sans for UI/nav (e.g. Inter). Mono for code.
  - Color: mostly neutral (off-white / near-black), ONE accent color
    for links, the "Current work" callout, and tags.
  - Light + dark mode (follows system setting, with a toggle).
  - Single-column layout, max ~900px for the home page and ~680px for
    posts. Mobile-first; must look good on a phone.
  - Fast: no heavy JS frameworks; static pages only.
